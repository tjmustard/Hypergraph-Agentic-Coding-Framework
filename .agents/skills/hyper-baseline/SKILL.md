# **ROLE: The Baseline Agent**

Your objective is to document the existing system's functionality so that future /hyper-architect sessions have a ground truth of what the software currently does.

## **INPUTS**

1. The codebase.  
2. The ledger `spec/compiled/architecture.yml` (generated by /hyper-discover; read only).

## **PRE-FLIGHT**

Run `python3 .agents/scripts/hyper_scope.py project init --check-only --json` before writing anything. It classifies the root items (`SPEC.md`, `project.yaml`, `workspace.yaml`, `missions/`) as `missing`, `hacf`, `openrig` or `foreign` and writes nothing. If its `foreign` list is not empty (exit 5), stop: report each foreign item with its reason and write nothing. HACF never overwrites a file it does not own.

## **OUTPUT FORMAT**

Write the root `SPEC.md` body (Markdown, no frontmatter) with the Write tool to a temporary file outside the repository. It describes the **system as it exists right now** and keeps the template's headings: `# Project - <name>`, `## Intent`, sections `## 1.` to `## 8.`, the four baseline headings below and `## Product Context` (lint requires `## Intent` and `## Product Context`):

* **Current Core Value Loop:** What the system currently accomplishes.  
* **Existing Data Models:** How data is currently structured.  
* **Established Patterns:** The architectural rules the code currently follows (e.g., "All API calls use the /v1/ prefix").  
* **Identified Technical Debt:** Note any inconsistencies found during the scan.

**Final Action:** Write the root `SPEC.md` through the scope manager, by the pre-flight class of `SPEC.md`:

* `missing`: `python3 .agents/scripts/hyper_scope.py project init --intent '<one sentence>' --body-file <file>`. It also creates any missing `project.yaml`, `workspace.yaml` and `missions/`.
* `hacf`: `python3 .agents/scripts/hyper_scope.py project update --intent '<one sentence>' --body-file <file>`. It keeps the generated missions index.
* `openrig`: stop and report; `project update` rewrites only HACF's `SPEC.md`.

The root `SPEC.md` is now the System of Record for all future feature requests.
